上传课件

使用有仓库写入权限的 GitHub 账号上传 PPT、PPTX 或 PDF。

在 GitHub 上传文件 →

  1. 将文件拖入 GitHub 上传页面。网页上传单个文件上限为 25 MiB。
  2. 点击 Commit changes 保存到 main；如需 Pull Request，合并后生效。
  3. 等待网站自动发布完成，课件会出现在对应课程下。

每节课可以上传多个文件，支持中文文件名。替换课件时使用相同文件名。上传的课件会公开供访客下载。
